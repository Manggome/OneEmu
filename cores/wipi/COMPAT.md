# 피처폰(WIPI) 호환 목록

`cores/wipi` 코어(dlunch/wie 기반)로 확인한 게임입니다. 게임 파일은 저장소에 없고, 각자 가진 덤프로 확인합니다.

상태 (wie 호환 목록과 같은 기준):
- **플레이 가능**: 끝까지 하는 데 큰 문제 없음
- **메뉴까지**: 메뉴는 되지만 게임 진행이 막힘
- **인트로까지**: 로고·인트로 뒤에 멈춤
- **실행 불가**: 시작하지 못함
- **미확인**: 아직 돌려 보지 않음

## 전체 결과 (장시간 자동 테스트, 2026-10-04)

`wipi_headless`(JIT) 로 폰에 넣은 46개 덤프 + 던전앤파이터 격투가편을 게임당 10분씩, 시드 3개 + 인터프리터 1회 돌린
결과 (첫 1분은 메뉴 진입 키, 이후 무작위 조작). 각 게임 화면을 직접 보고 상태를 매겼다 (`assets/compat.json`).

- 플레이 가능 41, 메뉴까지 5, 인트로까지 1 (하얀섬). MapleStory 시그너스는 첫 실행 때 "재실행" 안내 후 종료되는 게임 자체 동작.
- 이번에 고친 튕김: 리듬스타(랭킹 메뉴), 레전드오브마스터(배열 캐스트), 영웅서기4(전화걸기), 액션퍼즐패밀리4(파일 목록),
  질주쾌감스케쳐2(네트워크 표 범위), 학교가는길(Thread 레이아웃·게임종료), 놈ZERO(접속 콜백), 메이플 도적편(null 읽기),
  미니게임천국3, 루시안칼츠(atoi), 던전앤파이터 격투가편(하얀 화면 - 네이티브 화면 버퍼 공유)
- 게임을 닫을 때 에뮬레이터 전체(약 270MB)가 해제되지 않던 누수를 고쳐, 여러 게임을 연달아 열면 앱이 죽던 문제(SIGABRT)를 막았다.
- LGT: 네트워크 함수 묶음은 서비스 없는 폰처럼 실패(루시안칼츠 상점 → 접속 실패 안내 후 계속), 0x320대는 MC_uic*(슈퍼액션히어로3 이름 입력 튕김 해결).

## 앱에 표시되는 호환 정보

앱은 [`assets/compat.json`](assets/compat.json) 을 읽어 라이브러리에 색 점(초록 플레이 가능 … 빨강 실행 불가, 회색 미확인)과
게임 상세의 "호환성" 카드를 보여 준다. WIPI-X 처럼 **파일 단위**로 판정한다.

- 게임 파일의 SHA-256 이 목록에 있으면 그 상태 + "검증한 파일과 똑같은 파일"
- 해시는 다르지만 PID 가 같으면 같은 상태 + "다른 판본" 경고 (AID 는 여러 KTF 게임이 공유해서 쓰지 않는다)
- 둘 다 아니면 미확인

상태: `perfect`(완벽 호환 - 끝까지 플레이·게임 안 저장·재실행을 실기기에서 확인) > `playable` > `menu` > `intro` > `broken`.
`verified` 는 `manual`(사람이 실기기에서 확인) / `auto`(wipi_headless). `perfect` 는 `manual` 로만 준다.

앱은 이 파일을 APK 에 넣고, main 브랜치의 최신본을 하루 한 번 받아 `updated` 가 더 새로우면 바꿔 쓴다.
그래서 호환 결과는 앱 업데이트 없이 이 파일만 고쳐 main 에 올리면 퍼진다.

## 확인 방법

1. 게임 zip 을 `wipi_headless` 로 돌린다 (PC, `bash cores/wipi/build.sh --host`):
   ```
   cores/wipi/build/host/wipi_headless 게임.zip --frames 3600 --dump out/ --keys "300:OK,420:OK,600:5"
   ```
   로그에 통신사·제목·AID 가 찍히고, `out/` 에 1초마다 화면이 PPM 으로 남는다.
2. 단계별로 본다: 부팅 → 타이틀 → 메뉴 → 새 게임 → 5분 플레이 → 게임 안에서 저장 → 껐다 켜서 불러오기 →
   소리(배경음악·효과음) → 로그의 `Unimplemented` 경고 수.
3. 실기기(저가형 1대 + 중급 1대)에서 OneEmu 로 같은 순서를 반복하고 끊김·프레임 시간을 적는다.
4. 결과를 이 표에 적고, 게임별로 필요한 값은 `wie_libretro/quirks.toml` 에 AID/PID 와 함께 넣는다.
