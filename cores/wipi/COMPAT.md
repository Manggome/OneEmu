# 피처폰(WIPI) 호환 목록

OneEmu 피처폰 코어(dlunch/wie 기반)에서 **직접 최적화하고 확인한 게임 49개**입니다.
게임 파일은 저장소에 없고, 각자 가진 덤프로 확인합니다.

- 확인 방법: PC 자동 테스트(`wipi_headless`)로 게임마다 장시간 반복 플레이 + 실기기(갤럭시 S24+, Z 폴드) 점검
- 상태 기준: **플레이 가능** = 본게임을 진행하는 데 문제 없음 (49개 모두)
- **게임 치트**: 게임 메뉴(≡) → 치트 → "게임 치트"에서 원하는 숫자를 넣어 고정하거나 한 번만 바꿀 수 있는 항목
- 마지막 점검: 2026-10-18 (OneEmu v0.1.178)

> 앱 라이브러리의 색 점(초록 = 플레이 가능)과 게임 상세의 "호환성" 카드도 이 목록에서 나옵니다.
> 같은 게임이라도 **파일이 다르면** "다른 판본"으로 표시됩니다.

## 공통으로 알아 둘 것

- **저장**: 피처폰 게임은 세이브 스테이트 대신 **게임 안의 저장**을 씁니다. 저장 파일은 `OneEmu/saves/wipi/` 에 있습니다.
- **서버 기능**: 랭킹 등록, 유료 아이템 구매, 네트워크 대전처럼 옛 서버가 필요한 기능은 동작하지 않습니다.
  게임은 "접속 실패" 안내 뒤 그대로 계속됩니다.
- **화면 방향**: 게임 메뉴 → 화면 · 키패드 설정 → **화면 방향**에서 게임마다 자동 회전 / 폰 설정 따르기 / 세로 고정 /
  가로 고정을 고를 수 있습니다.
- **박스아트**: `OneEmu/boxart/` 에 `게임파일이름.png` 를 넣으면 그 그림이 썸네일로 쓰입니다.

## 개발자용

### 앱이 쓰는 호환 데이터

앱은 [`assets/compat.json`](assets/compat.json) 을 APK 에 넣고, main 브랜치의 최신본을 하루 한 번 받아
`updated` 가 더 새로우면 바꿔 씁니다. 그래서 호환 결과는 앱 업데이트 없이 이 파일만 고쳐 main 에 올리면 퍼집니다.

- 게임 파일의 SHA-256 이 목록에 있으면 그 상태, PID 만 같으면 "다른 판본" 경고, 둘 다 아니면 미확인
- `status`: `perfect`(끝까지·저장·재실행을 실기기에서 확인) > `playable` > `menu` > `intro` > `broken`
- `verified`: `manual`(사람이 실기기에서 확인) / `auto`(wipi_headless)
- `orientation`(선택): 화면 방향 기본값 — `portrait` / `landscape` / `system` / `auto`
- 게임 치트 목록은 [`assets/cheats.json`](assets/cheats.json) 에 있습니다 (PID, 없으면 파일 SHA-256 으로 매칭).

### 확인 방법

1. PC 에서 `bash cores/wipi/build.sh --host` 로 만든 `wipi_headless` 로 돌립니다.
   ```
   cores/wipi/build/host/wipi_headless 게임.zip --frames 3600 --dump out/ --keys "300:OK,420:OK,600:5"
   ```
   로그에 통신사·제목·PID 가 찍히고, `out/` 에 화면이 PPM 으로 남습니다. `--wav` 로 소리도 확인할 수 있습니다.
2. 부팅 → 타이틀 → 메뉴 → 새 게임 → 플레이 → 게임 안에서 저장 → 껐다 켜서 불러오기 → 소리 순서로 봅니다.
3. 실기기에서 같은 순서를 반복하고, 결과를 `compat.json` 과 이 문서에 적습니다.
