# OneEmu

옛날 게임기들을 **앱 하나로** 돌리는 안드로이드 에뮬레이터입니다. 패미컴부터 PS2까지, 기종마다
앱을 따로 깔 필요 없이 게임 폴더만 지정하면 알아서 분류하고 알맞은 코어로 실행합니다.

한국어 전용이고, 개인용으로 만들어 공개해 둔 것입니다. Play 스토어에는 올리지 않습니다.

> **게임 파일(ROM)과 BIOS 는 들어 있지 않습니다.** 직접 가진 게임기와 게임에서 뽑은 파일만
> 사용하세요. 이 앱은 게임을 구해 주지 않습니다.

## 어떤 기종이 되나요

| 기종 | 상태 |
| --- | --- |
| 패미컴 (NES / FDS) | 잘 됩니다 |
| 게임보이 · 컬러 · 어드밴스 | 잘 됩니다 |
| 닌텐도 DS | 잘 됩니다 |
| 메가드라이브 · 마스터 시스템 · 게임 기어 | 잘 됩니다 |
| 플레이스테이션 (PS1) | 잘 됩니다 |
| 아케이드 (오락실) | 잘 됩니다 · 롬셋 이름이 정확해야 합니다 |
| 닌텐도 3DS | 기기를 탑니다 · 고사양 필요 |
| PSP | 기기를 탑니다 |
| 게임큐브 · Wii | 기기를 탑니다 · 코어를 따로 받습니다 |
| 플레이스테이션 2 | 아직 느립니다 · 코어를 따로 받습니다 |
| 재즈 잭래빗 2 | 원본 PC 게임 파일이 있어야 합니다 |

## 무엇을 할 수 있나요

- **폴더만 지정하면** 게임을 알아서 찾아 기종별로 정리합니다
- **박스아트**를 인터넷에서 받아 붙입니다. 마음에 안 들면 직접 골라도 됩니다
- **화면의 조작 버튼**을 원하는 위치·크기로 옮길 수 있고, 게임기 모양 스킨도 씌울 수 있습니다
- **블루투스 패드** 지원. 두 개 연결하면 2인용이 됩니다. 버튼 배치도 바꿀 수 있습니다
- **언제든 저장하고 불러오기** (슬롯 9개 + 자동 저장)
- **빨리감기**, **연사**, **치트**, **스크린샷**
- **화면 효과** — 브라운관 스캔라인이나 LCD 격자를 씌워 옛날 느낌을 냅니다
- **세이브 백업** — 세이브·상태 저장·치트를 zip 하나로 내보내고 되돌립니다
- 새 버전이 나오면 앱이 알려 주고 그 자리에서 업데이트합니다

## 설치

1. [Releases](https://github.com/Manggome/OneEmu/releases) 에서 최신 `OneEmu-v...-arm64.apk` 를 받습니다
   (안드로이드 8.0 이상, 64비트 기기)
2. 받은 파일을 열면 "알 수 없는 앱 설치"를 허용하라고 합니다. 켜고 설치합니다
3. 처음 켜면 게임 폴더를 읽기 위해 **모든 파일 접근** 권한을 요청합니다. 허용해 주세요

## 게임 넣기

1. 게임 파일을 휴대폰 아무 폴더에나 넣습니다. 기종별로 폴더를 나눠 두면 더 정확합니다
   (예: `Games/GBA/`, `Games/NDS/`)
2. 앱에서 **라이브러리 → 폴더** 로 그 폴더를 추가하면 하위 폴더까지 훑습니다
3. 끝입니다. 목록에 뜨면 눌러서 실행하면 됩니다

압축된 `zip` 파일도 그대로 인식합니다. 디스크 게임(PS1·PS2·PSP)은 파일 안을 들여다보고
어느 기종인지 스스로 판단합니다.

<details>
<summary>기종별로 쓸 수 있는 파일 확장자</summary>

| 기종 | 확장자 |
| --- | --- |
| 패미컴 | `nes` `fds` `unf` `unif` `zip` |
| 게임보이 / 컬러 / 어드밴스 | `gb` `gbc` `gba` `sgb` `zip` |
| 닌텐도 DS | `nds` `dsi` `ids` `zip` |
| 메가드라이브 / 마스터 시스템 / 게임 기어 | `md` `gen` `smd` `sms` `gg` `zip` |
| PS1 | `cue`(+`bin`) `chd` `iso` `img` `pbp` `m3u`(여러 장) `mdf` `toc` |
| PSP | `iso` `cso` `pbp` `chd` `elf` `zip` |
| PS2 | `iso` `chd` `cso` `isz` `cue` `elf` |
| 게임큐브 / Wii | `iso` `gcm` `gcz` `rvz` `wbfs` `wia` `ciso` `dol` |
| 3DS | `3ds` `cci` `cxi` `app` `3dsx` (`cia` 는 안 됩니다) |
| 아케이드 | `zip` (파일 이름 = MAME 짧은 이름, 예: `sf2.zip`) |

</details>

## BIOS 가 필요한 기종

대부분은 BIOS 없이 그냥 됩니다. 아래는 있으면 더 잘 되거나, 있어야 되는 경우입니다.

앱에서 **설정 → 코어 / BIOS → BIOS 파일 가져오기** 로 고르면 알아서 제자리에 넣어 주고,
같은 화면에서 인식되었는지(✓ / ✗) 확인할 수 있습니다.

| 기종 | 파일 | 필요한 정도 |
| --- | --- | --- |
| PS1 | `scph5500.bin`(일본) `scph5501.bin`(북미) `scph5502.bin`(유럽) | 없어도 되지만 있으면 호환성이 좋아집니다 |
| 패미컴 디스크 시스템 | `disksys.rom` | `.fds` 게임에만 필요 |
| 게임보이 계열 | `gba_bios.bin` `gb_bios.bin` `gbc_bios.bin` | 없어도 됩니다 |
| 닌텐도 DS | `bios7.bin` `bios9.bin` `firmware.bin` | 없으면 내장 BIOS 로 돌아갑니다 |
| PS2 | 없음 | BIOS 없이 돌아갑니다 |
| PSP · 3DS · 아케이드 | 없음 | 필요 없습니다 |

아케이드는 BIOS 대신 **롬셋 이름**이 중요합니다. 네오지오 같은 기판은 `neogeo.zip` 을
게임 zip 과 같은 폴더에 두세요.

## 자주 묻는 것

**게임이 목록에 안 보여요** — 폴더를 추가했는지, 확장자가 위 표에 있는지 확인해 보세요.
라이브러리 메뉴의 **다시 스캔** 을 눌러도 됩니다.

**아케이드 게임이 안 돌아가요** — 롬셋 버전이 코어와 맞아야 합니다. 게임을 길게 눌러
**파일 정보** 를 보면 어디가 안 맞는지 알려 줍니다.

**세이브는 어디 있나요** — `Android/data/com.manggome.oneemu/files/saves/` 입니다.
설정 → 저장 데이터 에서 경로를 복사하거나 통째로 백업할 수 있습니다.

**업데이트했더니 설치가 안 돼요** — 예전에 다른 키로 서명된 버전이 깔려 있으면 덮어쓸 수
없습니다. 지우고 다시 설치하세요. 세이브는 위 폴더에 남아 있습니다.

## 만든 것에 대해

Kotlin + Jetpack Compose 로 만들었고, 에뮬레이션은 [libretro](https://www.libretro.com/) 코어들이
합니다. 코어는 소스에서 직접 빌드해 APK 에 넣거나 필요할 때 받아옵니다.

- 직접 빌드하거나 코어를 추가하려면 → [docs/BUILD.md](docs/BUILD.md)
- 코어를 만드는 규약 → [cores/README.md](cores/README.md)

## 라이선스

OneEmu 는 **GPL-3.0-or-later** 입니다 ([`LICENSE`](LICENSE)). GPL 코어를 함께 배포하기
때문입니다.

포함된 코어들의 라이선스는 [`THIRD-PARTY-LICENSES.md`](THIRD-PARTY-LICENSES.md) 에 정리해
두었습니다. 앱 안에서도 **설정 → 정보** 에서 볼 수 있습니다.

> ⚠ **일부 코어는 상업적 이용을 금지합니다** (Genesis Plus GX, MAME 2003-Plus, MAME 2010).
> 이 코어들이 들어 있는 한 OneEmu 를 팔거나 수익 목적으로 배포할 수 없습니다.
> 무료로 쓰고 나누는 것은 괜찮습니다.

OneEmu 는 게임 ROM, BIOS, 펌웨어, 암호화 키를 **포함하지도 배포하지도 않습니다.**
합법적으로 소유한 파일만 사용해야 하며, 그 책임은 사용자에게 있습니다.
