# OneEmu

옛날 게임기들을 **앱 하나로** 돌리는 안드로이드 에뮬레이터입니다.
패미컴부터 PS2, 그리고 **한국 피처폰(WIPI) 게임**까지 — 게임 폴더만 지정하면 알아서 분류하고 알맞은 코어로 실행합니다.

한국어 전용이고, 개인용으로 만들어 공개해 둔 것입니다. Play 스토어에는 올리지 않습니다.

> **게임 파일(ROM)과 BIOS 는 들어 있지 않습니다.** 직접 가진 게임기와 게임에서 뽑은 파일만 사용하세요.

## 주요 기능

**라이브러리**
- 폴더만 지정하면 게임을 찾아 **기종별로 정리**합니다 (zip 도 그대로 인식)
- **박스아트**를 인터넷에서 받아 붙입니다. `OneEmu/boxart/` 에 `게임파일이름.png` 를 넣으면 그 그림을 씁니다
- 아케이드 게임은 **한국어 이름**으로 보입니다 (보글보글, 메탈슬러그, 더 킹 오브 파이터즈 '97 …)

**플레이**
- **화면 버튼**을 원하는 위치·크기로 옮기고, 게임기 모양 **스킨**을 씌울 수 있습니다
- **블루투스 패드** 지원 — 두 개 연결하면 2인용, 버튼 배치도 바꿀 수 있습니다
- **언제든 저장·불러오기** (슬롯 9개 + 자동 저장), **빨리감기**, **연사**, **스크린샷**
- **화면 효과** — 브라운관 스캔라인이나 LCD 격자로 옛날 느낌을 냅니다
- 게임마다 **화면 방향**(자동 회전 / 세로 고정 / 가로 고정)을 정할 수 있습니다

**피처폰 게임**
- 실제 폰처럼 생긴 **키패드 화면**, 천지인 한글 입력
- **게임 치트** — 별·골드·HP 같은 값을 원하는 숫자로 고정하거나 한 번만 바꿉니다 (약 40개 게임)
- 게임 안 저장, 배경음악·효과음 지원

**관리**
- **세이브 백업** — 세이브·상태 저장·치트를 zip 하나로 내보내고 되돌립니다
- 새 버전이 나오면 앱이 알려 주고 그 자리에서 업데이트합니다

## 설치

1. [Releases](https://github.com/Manggome/OneEmu/releases/latest) 에서 `OneEmu-v...-arm64.apk` 를 받습니다
   (안드로이드 8.0 이상, 64비트 기기)
2. 받은 파일을 열고 "알 수 없는 앱 설치"를 허용한 뒤 설치합니다
3. 처음 켜면 게임 폴더를 읽기 위해 **모든 파일 접근** 권한을 요청합니다. 허용해 주세요

> **v0.1.171 이하를 쓰고 있다면** 이번 한 번만 앱을 지우고 새로 설치해야 합니다 (서명 키가 바뀌었습니다).
> 게임과 세이브는 `OneEmu` 폴더에 그대로 남고, 라이브러리 폴더만 다시 등록하면 됩니다.

## 게임 넣기

1. 게임 파일을 휴대폰 아무 폴더에나 넣습니다. 기종별로 나눠 두면 더 정확합니다 (예: `Games/GBA/`)
2. 앱에서 **라이브러리 → 폴더** 로 그 폴더를 추가합니다. 하위 폴더까지 훑습니다
3. 목록에 뜨면 눌러서 실행합니다

디스크 게임(PS1·PS2·PSP)은 파일 안을 들여다보고 어느 기종인지 스스로 판단합니다.

<details>
<summary><b>기종별 파일 확장자</b></summary>

| 기종 | 확장자 |
| --- | --- |
| 패미컴 | `nes` `fds` `unf` `unif` `zip` |
| 게임보이 / 컬러 / 어드밴스 | `gb` `gbc` `gba` `sgb` `zip` |
| 닌텐도 DS | `nds` `dsi` `ids` `zip` |
| 메가드라이브 / 마스터 시스템 / 게임 기어 | `md` `gen` `smd` `sms` `gg` `zip` |
| PS1 | `cue`(+`bin`) `chd` `iso` `img` `pbp` `m3u`(여러 장) `mdf` `toc` |
| PSP | `iso` `cso` `pbp` `chd` `elf` `zip` |
| PS2 | `iso` `chd` `cso` `isz` `cue` `elf` |
| 게임큐브 / Wii | `iso` `gcm` `gcz` `rvz` `wbfs` `wia` `ciso` `dol` |
| 3DS | `3ds` `cci` `cxi` `app` `3dsx` (`cia` 는 안 됩니다) |
| 아케이드 | `zip` (파일 이름 = MAME 짧은 이름, 예: `sf2.zip`) |
| 피처폰 (WIPI) | `zip` (게임 하나 = zip 하나), `jar`, `jad`(+`jar`) |

</details>

<details>
<summary><b>BIOS 가 필요한 기종</b></summary>

대부분은 BIOS 없이 됩니다. BIOS 는 **`OneEmu/system/`** 에 넣거나,
**설정 → 코어 / BIOS → BIOS 파일 가져오기** 로 고르면 알아서 제자리에 들어갑니다 (✓ / ✗ 로 확인 가능).

| 기종 | 파일 | 필요한 정도 |
| --- | --- | --- |
| PS1 | `scph5500.bin` `scph5501.bin` `scph5502.bin` | 없어도 되지만 있으면 호환성이 좋아집니다 |
| 패미컴 디스크 시스템 | `disksys.rom` | `.fds` 게임에만 필요 |
| 게임보이 계열 | `gba_bios.bin` `gb_bios.bin` `gbc_bios.bin` | 없어도 됩니다 |
| 닌텐도 DS | `bios7.bin` `bios9.bin` `firmware.bin` | 없으면 내장 BIOS 로 돌아갑니다 |
| PS2 · PSP · 3DS · 아케이드 · 피처폰 | 없음 | 필요 없습니다 |

아케이드는 BIOS 대신 **롬셋 이름**이 중요합니다. 네오지오 게임은 `neogeo.zip` 을 같은 폴더에 두세요.
네오지오·CPS1·CPS2·CPS3 게임은 FBNeo 코어(처음 실행할 때 내려받기)로 먼저 실행하고, 나머지는 MAME 코어가 맡습니다.

</details>

## 저장 위치

모든 데이터는 내장 저장공간 맨 위의 **`OneEmu`** 폴더에 모입니다. 앱을 지워도 남습니다.

```
OneEmu/
├─ saves/        세이브 (메모리카드, 피처폰 게임 저장 포함)
├─ states/       상태 저장
├─ system/       BIOS
├─ boxart/       직접 넣는 박스아트 (게임파일이름.png)
└─ screenshots/
```

**설정 → 저장 데이터** 에서 경로를 복사하거나 통째로 zip 으로 백업할 수 있습니다.

## 자주 묻는 것

**게임이 목록에 안 보여요** — 폴더를 추가했는지, 확장자가 위 표에 있는지 확인하세요. 라이브러리 메뉴의 **다시 스캔** 도 있습니다.

**아케이드 게임이 안 돌아가요** — 롬셋 버전이 코어와 맞아야 합니다. 게임을 길게 눌러 **파일 정보** 를 보면 어디가 안 맞는지 알려 줍니다.

**피처폰 게임이 이상해요** — [호환 목록](cores/wipi/COMPAT.md) 의 "알아 둘 것"을 먼저 보세요. 인증 화면이나 첫 실행 종료처럼 게임 자체 동작인 경우가 많습니다.

**업데이트했더니 설치가 안 돼요** — 다른 키로 서명된 예전 버전이 깔려 있으면 덮어쓸 수 없습니다. 지우고 다시 설치하세요. 세이브는 `OneEmu` 폴더에 남아 있습니다.

## 만든 것에 대해

Kotlin + Jetpack Compose 로 만들었고, 에뮬레이션은 [libretro](https://www.libretro.com/) 코어들이 합니다.
피처폰 코어는 [dlunch/wie](https://github.com/dlunch/wie) 에 OneEmu 의 호환 패치를 얹어 libretro 코어로 만든 것입니다.

- 직접 빌드하거나 코어를 추가하려면 → [docs/BUILD.md](docs/BUILD.md)
- 코어를 만드는 규약 → [cores/README.md](cores/README.md)
- 피처폰 코어와 호환 작업 → [cores/wipi/COMPAT.md](cores/wipi/COMPAT.md)

[`THIRD-PARTY-LICENSES.md`](THIRD-PARTY-LICENSES.md) 와 앱의 **설정 → 정보** 에서 볼 수 있습니다.

> ⚠ **일부 코어는 상업적 이용을 금지합니다** (Genesis Plus GX, MAME 2003-Plus, MAME 2010, FBNeo).
> 이 코어들이 들어 있는 한 OneEmu 를 팔거나 수익 목적으로 배포할 수 없습니다. 무료로 쓰고 나누는 것은 괜찮습니다.

OneEmu 는 게임 ROM, BIOS, 펌웨어, 암호화 키를 **포함하지도 배포하지도 않습니다.**
합법적으로 소유한 파일만 사용해야 하며, 그 책임은 사용자에게 있습니다.
